# Radar Tributário (CONTABIL)

Simulador fiscal moderno para planejamento tributário legal.

**Repositório:** https://github.com/Gabriel7z/CONTABIL

## Demo

Abra `index.html` ou publique via GitHub Pages.

## Funcionalidades

- Dashboard com KPIs e gráfico comparativo
- Simples Nacional · Lucro Presumido · Lucro Real
- Alertas de vencimento · Múltiplas empresas · Exportar PDF
